# 네이버 여행 후기 글쓰기 (밤밤 블로그)

목표: 검색 노출(D.I.A. 기준)이 되는 실제 체험 후기 글을, 밤밤의 톤으로, 재료만 받으면 바로 초안까지 만든다.

## 0. 시작 전 확인

- 블로그: blog.naver.com/bam_bam_2 (커뮤니티 콘텐츠 기획자 밤밤, 주제: 교육·학문)
- 이 블로그는 여행 주제 C-Rank가 없다. 경쟁 큰 키워드(예: "부산 여행")는 버리고
  **롱테일 키워드**(예: "부산워케이션 거점센터 후기", "영도 ○○카페 노트북")를 노린다.
- 발행 전 반드시 사용자 승인. 초안을 채팅으로 보여주고 승인 후 발행한다.
- 정보성 "○○ 하는 법" 글은 이 스킬이 아니라 `naver-howto-post` 스킬을 쓴다.

## 1. 사용자에게 받을 재료 (체크리스트)

**사진은 직접 가져올 수 있다**: 이 맥의 `~/Pictures/Photos Library.photoslibrary`에
아이폰 사진이 iCloud로 실시간 동기화된다 (2026-08-04 검증: 당일 사진까지 도착, 총 1.7만 장).
- 메타데이터: `database/Photos.sqlite`를 세션 tmp로 복사 후 sqlite3로 조회.
  `ZASSET` 테이블, 촬영일시 = `ZDATECREATED+978307200` (unixepoch), GPS = `ZLATITUDE/ZLONGITUDE`
  (-180 = 없음), 휴지통 제외 `ZTRASHEDSTATE=0`, 파일명 = `ZFILENAME`, 원본 = `originals/첫글자/UUID`
- 날짜+GPS로 여행 사진 추려서 후보 선정 → HEIC는 `sips -s format jpeg`로 변환 후 업로드
- 사진 선정은 초안과 함께 사용자에게 보여주고 승인받는다 (인물/사생활 사진 혼입 방지)
- **절대 규칙 (2026-08-04 밤밤 지시): 워크숍/행사 사진에서 진행자(밤밤) 외
  참가자 얼굴은 절대 노출 금지.** 얼굴 없는 컷(뒷모습/손/결과물)을 우선 선택하고,
  꿁 써야 하면 모자이크 처리 후 사용. 손글씨 실명, 회사 로고/사명 등 식별 정보도 동일하게 블러.
  모자이크 방법: 브라우저 캔버스로 영역 픽셀화 (drawImage 축소→확대, imageSmoothing off)
- 사진 업로드는 반드시 에디터 좌측 상단 '사진' 버튼 → 파일 직접 선택 (노출에 유리,
  글감/외부이미지 삽입 금지). 자동화는 filechooser 이벤트로 처리
- 저장공간 최적화로 원본이 로컬에 없는 과거 사진은 읽기 실패할 수 있음 → 그때만 사용자에게 요청

필수 (사진 외 물어볼 것):
- 장소명(정확한 상호)·지역, 방문 날짜/기간
- 사진 추가 필요 시에만: 원본 15장 이상 (직접 촬영)
- 실제 한 일 순서 (동선/코스, 대략의 타임라인)
- 돈: 가격, 예약 방법, 지원금/할인 받은 게 있으면 그 내역
- 한 줄씩: 제일 좋았던 것 / 아쉬웠던 것

선택 (있으면 글이 좋아짐):
- 꿀팁 (예약 타이밍, 자리, 메뉴, 주차 등)
- 다음 일정 예고 (시리즈면)
- 협찬/지원 여부 → **있으면 글 상단에 대가성 표기 필수** (공정위 심사지침)

재료가 부족하면 이 목록을 그대로 보여주고 부족한 항목만 요청한다. 없는 사실을 지어내지 않는다.

## 2. 글 기준 (네이버 D.I.A. 최적화)

**수치를 인용하기 전에 `naver-howto-post/references/naver-search-facts.md`를 먼저 읽는다.** 네이버 공식 확인 사항과 근거 없는 카더라 수치(C-Rank 가중치 40:30:20:10 등)가 구분돼 있다. 아래 수치들도 네이버 공식이 아니라 경험칙이니, 키워드마다 상위 글을 직접 재서 대조한다.

- 분량: **공백 제외 1,000~2,000자** (400자 미만·2,500자 초과는 감점 경향)
- 사진: **15장 이상**, 전부 사용자가 직접 찍은 것만. 스톡/캡처 금지
- 제목: 핵심 키워드 포함 + 내용을 그대로 말하는 담백한 제목.
  낚시·과장 금지. 예: "부산 워케이션 신청 방법과 거점센터 3박 후기"
- 제목에 쓴 키워드는 본문에서 실제로 다뤄야 함 (제목-본문 연관성이 다이아 점수)
- 키워드 반복은 자연스럽게, 총 20회 미만
- 검색의도 충족: 글 쓰기 전에 그 키워드로 검색해서 상위 1~5위 글이 다루는 정보를
  확인하고, 그들이 빠뜨린 것 1~2개를 더 넣는다
- 경험 신호: 구체 숫자(가격, 시간, 몇 분 거리), 실제 상황 묘사, 주관적 평가 포함
- 체류시간: 초반 3줄 안에 "이 글에 뭐가 있는지" 예고. 표/소제목으로 스캔 가능하게
- 발행 후 2~3일 지난 글은 수정하지 않는다 (미노출 위험). 고칠 게 있으면 새 글

## 3. 글 구조 템플릿

1. 도입 (3~4줄): 언제·어디를·왜 갔는지 + 이 글에서 알 수 있는 것.
   최근 밤밤 글처럼 인사말 없이 사실로 시작 ("지난 8월 18일, ...")
2. 정보 요약 표: 위치 / 이용시간 / 가격 / 예약방법 / 링크 (표 1개)
3. 본문 섹션 2~4개 (소제목 + 사진 3~5장씩):
   - 가는 법·첫인상 → 핵심 경험 (시간순) → 음식/공간/프로그램 디테일
   - 사진마다 한 줄 캡션 느낌의 문장을 붙인다
4. 꿀팁 목록 (3~5개, 번호 목록)
5. 아쉬운 점 1개 이상 솔직하게 (광고 글과 차별화되는 신뢰 신호)
6. 마무리 2~3줄: 총평 + 누구에게 추천하는지 (+ 시리즈면 다음 예고)
7. 지도(장소 첨부)와 태그 5~8개

## 4. 밤밤 톤 규칙

- 존댓말, 담백하게. 최근 글 기준: 사실 중심 문장 + 가끔 가벼운 감상 한 줄
- 이모지는 글 전체에 0~3개만 (😁 😳 수준). 문장마다 붙이지 않는다
- 금지 패턴 (사용자가 싫어하는 AI 카피 티):
  - "~이 아니라 ~이다" 대조 구문
  - "여정", "굴러가다", "~자리", "진짜 기준" 같은 은유
  - 안심시키기용 문장 ("걱정 안 하셔도 돼요", "절대 ~하지 않아요")
  - "완벽 가이드", "총정리 Zip" 같은 어그로형 제목
- 사실/지시/팁 문장은 남기고, 분위기 잡는 수사는 최소화

## 5. 작업 순서

1. 재료 수령 → 부족분 확인
2. 키워드 1개 선정 (네이버에서 검색량·경쟁 체크, 롱테일 우선)
3. 상위 노출 글 2~3개 훑고 빠진 정보 파악
4. 초안 작성 (구조 템플릿 + 톤 규칙) → 사진 배치 위치를 [사진: 설명]으로 표시
5. 채팅으로 초안 제시 → 승인
6. 발행: blog.naver.com 글쓰기(스마트에디터). 본문 붙여넣기 → 사진 업로드 →
   장소(지도) 첨부 → 태그 입력 → 발행. 발행 URL을 사용자에게 보고
7. 서포터즈/기자단 원고면 해당 프로그램의 가이드라인(글자수·필수 해시태그·대가성 문구)을
   먼저 확인하고 그 기준을 이 스킬 기준보다 우선한다

## 7. 티스토리 동시 운영

네이버 여행·공간 글을 발행할 때 같은 승인 건 안에서 티스토리용 글도 함께 준비한다.

- 티스토리 블로그명은 `커뮤니티 콘텐츠 기획자 밤밤`, 카테고리는 `워케이션·공간 답사`를 쓴다.
- 장소 정보만 나열하지 않고, 커뮤니티와 모임을 기획하는 밤밤이 공간을 어떻게 보고 사용했는지 포함한다.
- 네이버 원고를 그대로 복제하지 않는다. 티스토리는 이동·비용·공간 조건·업무 적합성·FAQ를 보강해 구글에서 독립적으로 읽히는 글로 다시 쓴다.
- quick-mosaic 등 도구 링크는 여행·공간 글에 관성적으로 넣지 않는다.
- 두 초안을 함께 보여주고 한 번 승인받은 뒤 각각 발행한다. 발행 후 티스토리 URL은 Google Search Console에서 색인 요청한다.
