## Phase 0. 오케스트레이터 — 인터뷰

스킬이 실행되면 **먼저 `references/00-lessons-learned.md`를 읽는다.**
기록된 시행착오를 파악한 뒤, 아래 질문을 순서대로 진행한다. 한 번에 2~3개씩 묻는다.

### 1라운드 질문 (필수)

```
안녕하세요! 커뮤니티 개설을 도와드릴게요.
몇 가지 여쭤볼게요.

1. 커뮤니티 이름 (아직 없으면 가칭 OK)
2. 한 줄로 설명하면? (어떤 사람들이, 무엇을 하는 곳인지)
3. 운영 호스트 이름 또는 닉네임
```

### 2라운드 질문 (필수)

```
4. 타겟: 어떤 사람을 위한 커뮤니티인가요?
   (직업, 상황, 고민 등 구체적으로)
5. 가격: 월정액 / 기수제 / 연간 중 어떤 구조로 생각하세요?
   그리고 예상 가격은요?
6. 운영 플랫폼: 카카오오픈채팅 / 디스코드 / 슬랙 / 기타?
```

### 3라운드 질문 (선택, 답하기 어려우면 넘어가도 됨)

```
7. 커뮤니티에서 정기적으로 할 활동이 있다면요?
   (예: 주 1회 줌 세션, 주간 과제, 챌린지 등)
8. 비슷한 커뮤니티와 차별화되는 점이 있다면요?
9. 1기 모집 목표 인원과 오픈 예정일은요?
```

모든 답변이 수집되면 → Phase 1부터 순서대로 실행.

## Phase 1. 기획 에이전트 실행

`references/01-planning-agent.md`를 읽고 커뮤니티 기획서를 작성한다.

완성 후 호스트에게 확인: "기획서 확인하셨나요? 수정할 부분 있으면 말씀해주세요. 없으면 다음 단계로 넘어갑니다."

---

## Phase 2. 카피라이팅 에이전트 실행

`references/02-copywriting-agent.md`를 읽고 채널별 모집 카피를 작성한다.

기본 출력: 스레드 모집 글 + 카카오 단톡방 공지
운영 플랫폼이 디스코드/인스타 등이면 해당 채널 카피 추가.

완성 후 호스트에게 확인 후 다음 단계 진행.

## Phase 3. 노션 에이전트 실행

`references/03-notion-agent.md`를 읽는다.

## Phase 5. 마무리 요약

모든 산출물 완성 후 아래 요약 출력:

```
✅ 커뮤니티 개설 패키지 완성

📋 기획서: [커뮤니티 이름] 기획서
✍️ 모집 카피: 스레드 글 + 단톡 공지
🗂️ 노션 DB: 멤버 / 콘텐츠 / 세션 DB
📌 SOP: 온보딩 / 주간 루틴 / 위기대응 / 기수 전환

다음 액션:
1. 결제 페이지 만들기 (래피드 권장)
2. 모집 글 발행
3. 노션 DB 세팅 확인
```

## 시행착오 로그 기록 방법

운영 중 새로운 인사이트가 생기면 호스트에게 물어본다:

> "이번에 [상황]이 있었는데, 시행착오 로그에 기록해둘까요?"

동의하면 `references/00-lessons-learned.md`에 아래 형식으로 추가:

```
### [커뮤니티명 또는 기수] — [날짜]

**상황**: ...
**시도한 것**: ...
**결과**: ...
**배운 것**: ...
**적용 범위**: 기획 / 모집카피 / 운영 / 노션 / SOP
```

## 운영 원칙

- 스킬 시작 시 반드시 `00-lessons-learned.md`를 먼저 읽어 과거 시행착오 반영
- 인터뷰 중 호스트가 답변하기 어려워하면 예시를 제시하고 선택하게 한다
- 각 Phase 완료 후 반드시 확인을 받고 다음으로 넘어간다
- 모든 산출물은 호스트의 말투와 컨셉을 반영해 작성한다
- 수정 요청이 들어오면 해당 Phase만 재실행한다
- 새로운 시행착오 발견 시 로그 기록을 제안한다
