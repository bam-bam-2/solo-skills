# 기획 에이전트 — 커뮤니티 기획서

인터뷰 데이터를 바탕으로 아래 구조의 기획서를 작성한다.

---

## 출력 형식

### 1. 커뮤니티 개요

| 항목 | 내용 |
|------|------|
| 이름 | |
| 한 줄 정의 | "누구를 위한, 무엇을 하는 커뮤니티" |
| 핵심 가치 | 3가지 이내 |
| 운영 플랫폼 | 카카오오픈채팅 / 디스코드 / 슬랙 등 |

### 2. 타겟 페르소나

- **이상적인 멤버**: 직업, 상황, 고민
- **진입 동기**: 왜 이 커뮤니티에 들어오는가
- **기대 결과**: 3개월 후 달라진 멤버의 모습

### 3. 포지셔닝

- 비슷한 커뮤니티와의 차별점 2~3가지
- 우리만의 언어/문화 (커뮤니티 고유 용어, 문화 제안)

### 4. 멤버십 구조

| 구분 | 가격 | 혜택 |
|------|------|------|
| 기본 | | |
| 프리미엄 (선택) | | |

- 결제 수단: 래피드 / 폼 등
- 환불 정책 제안

### 5. 커리큘럼 / 정기 활동

월별 또는 주제별 활동 로드맵 (3개월 기준)

| 기간 | 주제 | 활동 형태 |
|------|------|----------|
| 1개월차 | | |
| 2개월차 | | |
| 3개월차 | | |

### 6. 규칙 & 문화 헌장

- 가입 조건 (신청서 여부, 사전 인터뷰 여부)
- 활동 최소 기준
- 퇴장 기준
- 커뮤니티 분위기 한 문장 (예: "여기서는 완성보다 시도가 더 박수받습니다")

---

## 작성 원칙

- 추상적 표현 금지 → 구체적 숫자/행동으로 표현
- "좋은 커뮤니티"가 아닌 "이런 사람에게 이런 변화를 주는 커뮤니티"로 정의
- 호스트의 말투와 철학을 반영하여 작성
