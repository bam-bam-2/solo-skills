# SOP 에이전트 — 운영 표준 절차서

기획서 데이터를 기반으로 실제 운영에 바로 쓸 수 있는 SOP를 작성한다.

---

## 출력 1. 신규 멤버 온보딩 SOP

```
[ 신청 접수 ]
□ 신청서 수신 확인 (자동 or 수동)
□ 결제 확인
□ 노션 멤버 DB에 추가

[ 입장 안내 (입금 후 24시간 이내) ]
□ 환영 메시지 발송 (카카오 DM or 이메일)
□ 채널 초대 링크 전달
□ 커뮤니티 규칙 문서 링크 전달

[ 첫 주 활성화 ]
□ 자기소개 게시글 유도
□ 1:1 인사 메시지 (호스트 직접)
□ 첫 번째 세션/활동 안내
```

---

## 출력 2. 주간 운영 루틴 SOP

```
[월요일]
□ 주간 목표/과제 공지
□ 지난 주 우수 활동 멤버 언급 (선택)

[수요일]
□ 중간 점검 메시지
□ 콘텐츠 발행 (계획된 경우)

[금요일]
□ 주간 마무리 공지
□ 다음 주 일정 예고

[월별]
□ 수료/우수 멤버 선정 및 공개 인정
□ 멤버 활동 지표 확인 (활성 멤버 비율)
□ 다음 기수 모집 여부 검토
```

---

## 출력 3. 위기 대응 SOP

**멤버 불만 발생 시**
```
1. 24시간 이내 개인 DM 응답
2. 문제 파악 → 해결 방안 제시
3. 공개 해결이 필요하면 커뮤니티에 공지
4. 반복 불만 시 환불 정책 안내
```

**멤버 탈퇴/비활성 시**
```
1. 비활성 2주 이상 → 체크인 메시지
2. 응답 없을 시 → 다음 기수 미연장 안내
3. 탈퇴 요청 시 → 환불 정책에 따라 처리
```

---

## 출력 4. 기수 마무리 & 다음 기수 전환 SOP

```
[ 종료 2주 전 ]
□ 수료 기준 재공지
□ 다음 기수 모집 예고 (재등록 우선권 안내)

[ 종료 당일 ]
□ 수료 인증 발송
□ 후기 요청 (스레드 or 구글폼)

[ 종료 후 1주 ]
□ 후기 취합 → 다음 모집 카피에 활용
□ 노션 멤버 DB 상태 → 수료 처리
□ 다음 기수 모집 글 발행
```

---

## 작성 원칙

- 체크박스 형식으로 실행 가능하게
- 담당자 표기 필요 시 [호스트] / [운영진] 구분
- 자동화 가능한 부분은 별도 표시 (예: ★자동화 가능)
