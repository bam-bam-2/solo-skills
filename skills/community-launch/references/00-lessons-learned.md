# 시행착오 로그 — 커뮤니티 운영 경험 기록

실제 운영하면서 겪은 시행착오와 인사이트를 기록하는 파일.
에이전트는 기획/카피/운영 조언 시 이 파일을 먼저 참고하여 과거 실수를 반복하지 않는다.

---

## 기록 형식

```
### [커뮤니티명 또는 기수] — [날짜]

**상황**: 어떤 상황이었는지
**시도한 것**: 무엇을 해봤는지
**결과**: 어떻게 됐는지
**배운 것**: 다음에 어떻게 다르게 할 것인지
**적용 범위**: 기획 / 모집카피 / 운영 / 노션 / SOP
```

## 에이전트 활용 지침

이 파일을 읽는 에이전트는:
1. "배운 것" 항목을 현재 작업에 즉시 반영한다
2. 유사한 상황이 감지되면 먼저 경고한다
   예: "이전에 [상황]에서 [문제]가 있었어요. [배운 것] 기반으로 이렇게 하는 게 낫겠습니다"
3. "잘 됐던 것"은 별도 지시 없이 기본값으로 채택한다
