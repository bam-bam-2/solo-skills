## C. 실측 데이터 (직접 측정한 것)

### 2026-08-08 · 키워드 "카톡 캡처 모자이크" 블로그탭 상위 7개

본문 컨테이너(`.se-main-container`) 안에서만 측정. UI 아이콘·사이드바 제외.

| 항목 | 중앙값 | 범위 |
|---|---|---|
| 글자수(공백 제외) | **1,306자** | 697 ~ 2,045 |
| 본문 이미지 | **22장** | 12 ~ 35 |
| 동영상 삽입 | 0개 | 7개 중 1개만 있음 |
| **외부 사이트 링크** | **0개** | 7개 전부 0 |
| 태그 | 3~5개 | 0 ~ 12 |
| 소제목/구분선 구조 | 대부분 있음 | 0 ~ 12 |

**여기서 끌어낼 수 있는 것:**
- 이 키워드대는 **2,000자 넘길 필요가 없다.** 1,200~1,800자에 스크린샷을 촘촘히 까는 형태가 상위권
- **이미지가 글자보다 중요하다.** 20장 안팎의 단계별 스크린샷이 사실상 표준
- **외부 링크는 랭킹에 도움이 안 된다** (상위 전부 0개). 링크는 유입 목적으로만 1~2개, 본문 흐름 안에서 자연스럽게
- 동영상은 거의 아무도 안 넣는다 → 노출 이득은 미확인이지만 **체류시간·차별화 측면에서 넣을 가치는 있음**

### 같은 조사에서 확인한 내용 빈틈
상위 글들이 공통으로 다루는 것: 카카오톡 자체 익명 캡처 기능, 폰 갤러리 편집기 모자이크.

- **PC/맥에서 캡처한 이미지** (카톡 익명 캡처 기능이 안 통하는 상황)
- 카톡이 아닌 앱(인스타·라인·디스코드 등) 캡처
- **계좌번호·주소 같은 텍스트 개인정보** 가리기
- 웹에서 바로 처리하는 도구

## D. 재측정 방법 (다음에 또 잴 때)

네이버 블로그 본문은 `#mainFrame` iframe 안에 있다. iframe 안으로 들어가서 `.se-main-container` 기준으로 세야 정확하다.

```js
const d = document.getElementById('mainFrame').contentDocument;
const main = d.querySelector('.se-main-container');
main.innerText.replace(/\s/g,'').length;                 // 글자수(공백 제외)
main.querySelectorAll('.se-module-image').length;        // 본문 이미지
main.querySelectorAll('.se-module-video').length;        // 동영상
[...main.querySelectorAll('a[href^="http"]')]
  .filter(a => !/naver\.com|naver\.me/.test(a.href)).length; // 외부 링크
```

`document.querySelectorAll('img')` 로 세면 사이드바·UI 아이콘까지 잡혀서 95장 같은 말도 안 되는 값이 나온다. 실제로 한 번 그렇게 틀렸다.
