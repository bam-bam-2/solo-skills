# 커뮤니티 행사 단톡 판매 7단계 프레임워크

> 출처: 다오랩 단체카카오톡방 내 '다오콘:연결지능(2026)' 판매 실전 사례 분석
> 행사 결과: 슈퍼얼리버드 3일 완판 + 전체 완판 + 대기자 29명

---

## 단계별 전략 원칙

### STEP 1. 선공개 공지 — "최초 공개" 포지셔닝

**원칙:** 내부 전용 + 한정 수량 + 최저가 3요소를 **첫 문장**에 배치. 외부에 아직 안 알렸다는 사실이 수신자를 특별하게 만든다.

**구성 요소:**
- 행사명 + 한 줄 설명
- "크루/멤버/지인 전용 최초 공개" 명시
- 가격 (단계별 인상 구조 예고)
- 한정 수량 + 마감 날짜
- 신청 방법 (계좌이체 + 구글폼 / 링크)

**실전 원문 (다오콘 사례):**
```
다오랩 크루와 크루 지인을 대상으로 최초로 공개합니다.
가장 저렴한 가격에 다오랩 크루들에게 혜택을 드리고자 준비했으니
100장 한정으로 선착순으로 11일(일)까지 신청받습니다.
```

---

### STEP 2. 즉시 개별 DM — 초기 모멘텀 생성

**원칙:** 공지 올라온 직후(당일) 주도자가 핵심 멤버에게 개별 메시지. 단톡방이 반응하기 전에 초기 구매자를 확보해 리스트가 빠르게 채워지게 만든다.

**구성 요소:**
- 공지 링크 or 요약
- "생각보다 빨리 마감될 것 같다"는 긴박감
- 1:1 초대감 ("특별히 먼저 알려드려요")

**실전 원문 (다오콘 사례):**
```
[신지현, 공지 8분 후]
저도 지인들한테 개별메시지로 뿌렸거든요.
생각보다 빨리 마감될수도 있을것 같아요.
점심 포함 5만원 / 책 패키지는 7만원이라 진짜 매력적인 가격입니다.
```

---

### STEP 3. 실시간 리스트 공개 — 사회적 증거 누적

**원칙:** 구매자가 직접 리스트에 이름 추가. 단톡방 피드 = 구매 완료 알림. 구매가 "당연한 분위기"가 된다. 지인 소개 시 "이름 - 소개자 지인" 형식으로 바이럴 출처도 기록.

**리스트 형식:**
```
< [행사명] 신청 및 이체 완료 리스트 >
[링크]
1. 홍길동
2. 김철수
3. 이영희 - 홍길동 지인
4. 박민수 (+1)
```

**실전 원문 (다오콘 사례):**
```
[한재선님, 공지 당일 오후]
벌써 14장 티켓이 판매됬네요. 성원에 감사드려요.
제가 다오랩 통장을 매번 확인하기 어려우니
이체 완료하시면 아래 리스트에 추가 부탁드립니다.
```
→ 이후 구매자 15명 이상이 직접 리스트를 이어서 업데이트

---

### STEP 4. 카운트다운 메시지 — 마감 임박 압박

**원칙:** 마감 D-1 또는 D-0 **아침 첫 메시지**로 잔여 수량 공개. 이후 가격 인상 반드시 명시. 압박 뒤엔 반드시 감사/다짐으로 마무리해 차갑지 않게.

**구성 공식:**
```
[현재 판매량] 매입니다. [남은 수량] 매 남았네요.
[마감 예고 — "오늘 중/이번 주"].
이후에는 [다음 단계] 가격으로 올라갑니다.
[감사 + 기대 한 줄]
```

**실전 원문 (다오콘 사례):**
```
[신지현, 마감 당일 오전 7:34]
굿모닝입니다. 티켓신청이 87매입니다. 13매 남았네요.
성원에 진심으로 감사드려요. 오늘 중 마감될 것 같은데...
이후에는 외부공개되는 얼리버드, 일반티켓으로 가격이 올라갑니다.
이번 슈퍼얼리버드를 경험하면서 더 열심히 준비해야겠다 다짐해봅니다.
```

---

### STEP 5. 정기 업데이트 — 수치 + 의미 세트

**원칙:** 판매 현황 숫자만 던지지 않는다. 반드시 행사 의미 또는 준비 에피소드를 붙여 "이 행사가 잘 만들어지고 있다"는 신뢰 신호를 준다. 1~2주 간격.

**구성 공식:**
```
[현황 수치] + [놀라운 점 강조] + [남은 기회] + [행사 가치/의미] + [링크]
```

**실전 원문 (다오콘 사례):**
```
[신지현, 판매 2주차]
점심 맛있게 드셨나요? < 다오콘 : 연결지능 > 업데이트 드립니다.

연사/패널 정보 없이 블라인드 티켓으로 다오랩 내부에서 100장도 이틀만에 마감되었는데
정말 놀라운 결과네요. 현재 300장 유료티켓 중 239장 나가서 61장 남은 상황입니다.

보다 많은 분들이 합리적인 가격에 참여하실 수 있도록 1/31까지 얼리버드를 연장합니다.
```

---

### STEP 6. 설문 + 경품 연동 — 참여자를 공동 제작자로

**원칙:** 설문 = 경품 조건 + 세션 소재. 결과 티저 공개로 행사 당일 호기심 유발. 참석자가 "이 행사를 함께 만들었다"는 감각을 갖게 된다.

**구성 공식:**
```
설문 안내 + "경품 조건" 명시 + 설문 결과 일부 티저 + "나머지는 현장에서"
```

**실전 원문 (다오콘 사례):**
```
[신지현, 행사 D-13]
다오콘 신청하신 분들~ 설문 꼭 참여하세요.
그래야 경품 추첨대상이 되실 수 있어요. ^^
설문 답변으로 Interactive Session을 준비할 예정이에요~

현재까지 85건 응답 중 재밌는 포인트:
설문응답자 중 반 이상이 커뮤니티 2-3개 참여중이에요.
가장 많은 MBTI 유형은 ... 바로바로 ... ENFJ입니다.
더 흥미로운 내용이 많아요~ 결과는 현장에서...
```

---

### STEP 7. 완판 공지 — 축제화

**원칙:** 완판을 조용히 넘기지 않는다. 수치 + 감사 + 의미 부여 + 기대감 4단으로 공표. 구매자에게 "좋은 결정"을 확인해주고, 미구매자에게는 다음 기회 기대감을 심는다.

**구성 공식:**
```
[감탄/이모티콘] + [완판 선언] + [수치] + [감사] + [의미] + [기대감 + 만남 예고]
```

**실전 원문 (다오콘 사례):**
```
[신지현]
굿모닝, 🥳 🎉 🎈🎊

[다오콘:연결지능] 티켓 완판입니다!
슈퍼얼리버드 포함 145 / 301

정말 신기하고 감사한 일이네요.
슈퍼얼리버드 이틀만에 마감. 얼리버드 기간 모든 티켓 완판이라니~
애정 열정 담아 열심히 지원사격 해주신 덕분입니다.

이제 마음 편하게 컨퍼런스만 멋지게 준비하면 되겠어요~
즐길 준비 되셨죠? 행사에서 뵈어요. 감사합니다!
```

## 채널별 톤 가이드

| 채널 | 톤 | 특징 |
|------|-----|------|
| 카카오톡 단톡방 | 친근 + 공식 혼합 | 리스트 업데이트, 이체 안내, 실시간 반응 중심 |
| 스레드 | 가볍고 공감형 | 이야기 중심, 홍보처럼 안 보이게, 짧게 끊기 |

### 카카오톡 단톡방 특징
- 리스트 직접 붙여넣기 가능
- 공지/게시판 기능 활용
- 이체 후 이름 추가 유도 가능
- 멘션(@이름) 활용해 개별 촉구

### 스레드 특징
- 긴 공지 대신 "이야기 + 링크" 구조
- "홍보처럼 보이지 않게" — 개인 경험/소감 중심
- 댓글로 추가 정보 이어붙이기
- 해시태그 활용 (#행사명 #커뮤니티)

**스레드용 공식 (다오콘 사례):**
```
[한재선님, 스레드]
'내가 커뮤니티에 진심인 이유'라는 글을 적어봤어요.
목적은 다오콘의 홍보이지만 홍보처럼 보이지 않게 노력했어요.
```
