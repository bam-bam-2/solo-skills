# 녹화본 디스코드 공지 (2026-09-07 7기 OT 실측)

`#겟백-세션-녹화본` 포럼(id `<DISCORD_ID>`)에 **밤냥이 봇 명의로** 새 스레드를 만든다.

## 왜 봇 명의여야 하나

봇의 `recording_expiry.py`가 **봇이 쓴 글만 편집할 수 있다.** 밤밤 계정으로 올리면 시청 기한이 안 붙고 링크도 안 지워진다(남의 메시지는 API로 편집 불가).

## 양식

1기부터 6기까지 지켜온 구조다. 순서를 바꾸지 않는다.

```
**[겟백] N기 OT — 부제**

<@&{역할ID}>

세션 요약이에요.

📌 **핵심 주제**
(3~4문장. 이번 회차가 무엇을 다뤘는지)

✨ **주요 내용**
• **소제목** — 설명 2~3문장
(6개)

💡 **핵심 메시지**
(한 문장. 가능하면 밤밤이 실제로 한 말)

━━━━━━━━━━

📋 **못 본 사람이 지금 할 일**
• (강의에서 실제로 지시한 것만. 4~5개)

⏱️ **왜 봐야 하는지**
(3~4문장. 이 회차를 안 보면 뒤 세션에서 뭐가 막히는지 중심)

━━━━━━━━━━

📺 https://youtu.be/{VIDEO_ID}
```

제목은 스레드 이름과 본문 첫 줄에 **둘 다** 들어간다.

## 기수 역할 멘션

`<@&{역할ID}>` + `allowed_mentions: {"parse": ["roles"]}`. 이게 없으면 멘션이 텍스트로만 뜨고 알림이 안 간다.

기수 역할은 매 기수 새로 만들어야 한다(2026-09-07 기준 7기 = `<DISCORD_ID>`). 역할이 없으면 `POST /guilds/{guild}/roles`로 만들고 위치를 이전 기수 바로 위로 옮긴다. 같은 시점에 **기수 태그가 있는 포럼 채널 8곳**(피어러닝·get100-한달-성과·데일리-스레드·터진글-아카이브·자기소개·스레드-프로필·워크숍-후기·블로그)에도 새 기수 태그를 추가한다.

## 내용을 만드는 법

전사본을 서브에이전트에 넘겨 뽑되, **강의에 실제로 나온 것만** 쓴다. 특히 "못 본 사람이 지금 할 일"은 추측해서 만들지 않는다 — 밤밤이 실제로 지시한 과제만 적고, 없으면 없다고 한다.

숫자는 그대로 인용하되 **공개 범위를 한 번 확인한다.** 2026-09-07 요약에는 "월 순수익 1,500만 원"이 들어갔는데, 강의에서 실제로 한 말이라도 공개 글에 넣을지는 밤밤이 정한다.

금지 표현은 `memory/USER.md` 기준을 그대로 따른다 — "~이 아니라 ~이다" 대조 구문, "굴러가다", "자리", "여정", 방어적 문장.

## 시청 기한

`recording_expiry.py` 상수:

- `EXPIRY_DAYS` — 2026-09-08부터 **7일**(그전 14일). 바꾸면 맥미니에 복사하고 봇을 재시작해야 반영된다(`launchctl kickstart -k gui/$(id -u)/com.getback.bamnyangi`). 기동 로그 `~/Projects/getback/discord_bot/bamnyangi.log`에서 `✓ recording_expiry 등록 (녹화본 N일 기한)` 확인.
- `APPLY_FROM` — 이 시각 이전 글은 영원히 안 건드린다.
- 스윕은 1시간 주기라 게시 직후에는 기한 표기가 없다. 조급해하지 않는다.
- 기한이 지나도 **글은 남고 유튜브 링크만 지워진다.** 나중에 다시 열려면 본문에 링크을 다시 넣으면 된다.

## 검증

게시 후 `GET /channels/{thread}/messages/{thread}`로 첫 메시지를 읽어 확인한다.

- `mention_roles`에 기수 역할 ID가 있는가
- 유튜브 링크가 본문에 있는가
- (1시간 뒤) `🗓 시청 기한:` 이 붙었는가
