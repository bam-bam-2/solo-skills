# 실측에서 걸린 함정 (2026-09-07)

## 소스·싱크
- 맥 `화면 기록`(QuickTime)은 **오디오가 없다.** 음성은 다른 녹화(디스코드 화면 녹화 등)에서 가져와야 하고, 두 파일 시작 시각이 다르다. 오프셋은 "슬라이드 제목을 읽는 발화 시각"과 그 슬라이드가 화면에 뜬 시각을 두 군데 이상에서 맞춰 확정한다. 슬라이드 전환 scene 검출은 스크롤·커서 움직임에도 반응하므로 단독으로 믿지 말 것.
- 화면 공유가 끝나면 맥 화면기록에는 디스코드 UI(참가자 이름·아바타·채팅)가 그대로 찍힌다. 슬라이드 크롭 영역이 그 시점부터 참가자 정보를 담게 되니 **구간을 나눠서** 2부는 웹캠 타일만 크롭한다.
- 웹캠 타일 위치는 레이아웃(공유 중/공유 해제/타인 공유)마다 바뀐다. 30초~5분 간격으로 크롭 샘플을 뽑아 콘택트시트로 확인하고, 유효 시작 시각(`valid_from`)과 덮을 구간(`cover`)을 잡는다.
- 상대 녹화의 웹캠 타일이 작으면(316px) 업스케일이 흐리다. 가능하면 해상도 높은 쪽(맥 2880x1800)의 타일을 쓴다.

## 전사
- 2시간짜리를 whisper에 한 번에 넣으면 **80분 이후 "하하하", "네" 반복 환각**이 난다. 반드시 10분 청크 + `--condition-on-previous-text False`. 청크별 글자 수가 균일한지(10분당 3천자 안팎) 표로 확인한다.
- 실제 발화 끝은 전사가 아니라 **볼륨 측정**(`volumedetect`)과 청크 재전사로 판단한다. 환각 구간을 "끝났다"고 오판하면 25분을 잘라먹는다.
- 교정은 문장 단위 청크(120줄)로 claude -p sonnet. 줄 수가 안 맞으면 재시도. 단어 수가 바뀐 줄은 `apply_fix.py`가 글자 수 비례로 타임스탬프를 재배분한다.

## ffmpeg
- 맥미니 홈브루 `ffmpeg`(core)는 **libass·freetype 없이** 빌드돼 `ass`/`subtitles`/`drawtext`가 없다. `brew install ffmpeg-full` 후 `/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg`를 쓴다(keg-only).
- `crop` 필터는 폭·높이에 `t`를 못 쓴다(초기화 때 한 번 평가). 시간에 따른 확대는 `zoompan`(d=1, s=1920x1080, fps=30)으로. x/y 식은 "팬 범위 내 비율": `fx*(iw-iw/zoom)`. 0이면 왼쪽 끝. 가운데 좌표로 착각하면 왼쪽 콘텐츠가 잘린다.
- `-loop 1 -i 이미지`를 넣으면 입력이 무한이 된다. **출력 옵션으로 `-t`를 반드시 준다**(입력 쪽 `-ss -t`만으로는 안 끝난다). 실제로 5시간 46분짜리가 렌더된 적 있음.
- ASS `BorderStyle=4` + `BackColour &H96000000`이면 반투명 띠가 깔려 슬라이드 하단 글과 겹쳐도 읽힌다. 외곽선만 쓰면(BorderStyle=1) 흰 배경·글자 위에서 깨진다.
- 카라오케 하이라이트 색을 라임(#D4F000)으로 하면 라임 슬라이드에서 사라진다. 보라(&H00FF2F7B)가 라임·흰·검정 모두에서 보인다.
- 주아체에는 ①② · → 글리프가 없다. 숫자는 "1.", 가운뎃점은 쉼표, 화살표는 폴리곤으로 그린다.
- `pkill -f 스크립트명`은 자기 자신(그 이름이 들어간 bash -c)도 죽인다. `pkill -f '[p]rep.sh'`처럼 대괄호 트릭을 쓴다.

## 전송·자원
- 맥북에어→맥미니 테일스케일은 5MB/s. 원본(11GB+8GB)을 보내지 말고 **맥북에서 videotoolbox로 크롭·축소본을 먼저 뽑아**(1080p 3500k, 타일 2500k) 2~3GB만 보낸다.
- 맥미니 M4에서 1080p 필터 렌더는 단독 5~9배속. 1부·2부를 동시에 돌리면 각각 1.6배속으로 떨어지니 총 시간은 같다.


## 줌 클라우드 소스 (2026-09-07 추가)

- **`segs_final.json`에 `words`가 없으면 `make_video.py`가 `KeyError: 'words'`로 죽는다.** 줌 전사본은 문장 단위라 어절 타임스탬프가 없다. `scripts/add_words.py`로 글자 수 비례 배분을 먼저 돌린다. whisper 경로로 왔으면 이미 들어 있으니 건너뛴다.
- **줌 API 자격증명이 `.env`에 있어도 옛날 앱 것일 수 있다.** `invalid_client / The app has been disabled by the developer`가 뜨면 앱이 꺼진 게 아니라 값이 낡은 것이다. 마켓플레이스에서 현재 앱의 Account ID·Client ID·Secret을 읽어 갱신한다.
- 줌 녹화는 **1760x900 25fps**다. 1920x1080 30fps로 올려야 파이프라인에 맞는다. videotoolbox로 111분 → 약 8분, 2.7GB.
- 인코딩이 끝나기 전에 `ffprobe`를 걸면 `moov atom not found`가 난다. `pgrep -f h264_videotoolbox`로 종료를 확인하고 검사한다.
- **화면이 계속 바뀌는 소스에는 슬라이드 구간표를 만들지 않는다.** 줌 창 전체 녹화는 슬라이드·브라우저·웹캠이 번갈아 나와서 타이틀카드가 엉뚱한 화면에 뜬다. `runs`를 통짜 하나로 두고 `titles`·`zoom`·`illustrations`를 비운다.
- `montage`(ImageMagick)는 폰트 설정이 없으면 `unable to read font`로 실패한다. 콘택트시트는 `ffmpeg -pattern_type glob -i "qa/q_*.jpg" -filter_complex tile=4x2`로 만든다. 이때 파일명은 `q_00030.jpg`처럼 자리수를 맞춰야 정렬이 맞고, `format=yuvj420p`를 넣어야 mjpeg 인코더가 안 죽는다.

## 배포 (2026-09-07 추가)

- 디스코드 파일 첨부는 8MB 제한이라 **녹화본은 유튜브 unlisted로 올리고 링크만 건다.** 1기부터 이 방식이었다.
- `recording_expiry.py`는 **봇이 쓴 글만 편집한다.** 밤밤 계정으로 올리면 시청 기한이 안 붙고 링크도 안 지워진다.
- 기수 역할 멘션은 `allowed_mentions: {"parse": ["roles"]}`가 있어야 알림이 간다. 없으면 텍스트로만 보인다.
- `EXPIRY_DAYS`를 바꾸면 맥미니에 복사하고 봇을 재시작해야 반영된다. 기동 로그에서 `✓ recording_expiry 등록 (녹화본 N일 기한)`을 확인한다.

## 렌더 속도와 접속 (2026-09-08 7기 1주차 실측)

- **`make_video.py`가 만든 `render.sh`를 그대로 돌리지 말 것.** 기본이 `zoompan` + `libx264 -preset medium`인데,
  `zoom`을 비운 경량 경로에서 zoompan은 아무 일도 안 하면서 속도만 깎는다.
  **zoompan을 빼고 `-preset fast -crf 20`으로 바꾸면 13배속**(126분 → 9분 36초, 718MB)이 나온다.
  하드웨어 인코더(videotoolbox)는 7.5배속으로 더 느리고 화면 콘텐츠에서 파일이 5배 커진다. **x264가 낫다.**
- **속도 측정을 `-ss`로 하지 말 것.** `-i base.mp4 ... -ss 4180 -t 60`은 출력측 시킹이라
  4180초를 전부 디코딩한 뒤에야 쓰기 시작한다. 0.27배속처럼 보여 8시간짜리로 오판하게 된다.
  벤치마크는 **0초부터 `-t 90`**으로 잰다. 실제 렌더도 0초 시작이라 이게 맞는 조건이다.
- **자막 확인용 프레임을 뽑을 땐 `-ss`를 입력 앞에 두면 안 된다.** 입력측 시킹은 타임스탬프를 0으로
  리셋해서 그 시점 자막이 안 나온다. `-i` 뒤에 둬야 `.ass` 시각과 맞는다.
- **맥미니 접속 경로는 두 개다.** 테일스케일(`mac-mini`)이 죽어도 핑은 13ms로 정상 응답하므로
  포트가 열렸는지로 판단한다(`nc -z -w5 100.75.197.6 22`). 막혔으면 **`mac-mini-lan`(mac-mini.local)**으로
  우회한다. 반대로 LAN 이름 해석이 실패하는 때도 있으니 **둘 다 시도**한다.
  2026-09-08 새벽엔 테일스케일이 막히고 LAN이 됐는데, 같은 날 오후엔 정반대였다.
- 맥에 `pdfinfo`(poppler)가 없어 `_slides_to_pdf.py`가 마지막 검증에서 죽지만 **PDF는 정상 생성**된다.
  페이지 수는 `re.findall(rb'/Type\s*/Page[^s]', data)`로 따로 센다.
- 줌 API의 `duration`(회의 시간)과 **녹화 파일 길이는 다르다.** 7기 1주차는 API 165분 / 실제 125분 50초였다.
  `config.json`의 `end`는 `ffprobe`로 잰 실제 길이로 넣는다.
