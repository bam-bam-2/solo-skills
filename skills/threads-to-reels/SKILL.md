# 스레드 → 인스타 릴스

밤밤의 스레드 성과글을 소재로 잡고, 아이폰 사진 라이브러리에서 그 시기 사진을 찾아 붙여
인스타 릴스(1080×1920)를 만든다. 발행 계정은 `get100.official`.

무거운 작업(렌더·전사·학습)은 전부 **맥미니**에서 돌린다. 맥북에어엔 ffmpeg도 Pillow도 없다.
`ssh -o BatchMode=yes mac-mini`

근거와 수치는 볼트 `개념/보이스 클로닝.md`.

대본이 정해지면 이렇게 요청한다.

녹음이 오면 `~/voicememo/inbox/` 에서 최신 파일을 집어 문장 단위로 자르고 정렬한다.

## 1. 소재 선정

`~/Projects/ops/threads-tool/.env` 토큰으로 글 인사이트를 전량 수집해 성과 상위를 뽑는다.
**주의: 성과 1위 글이 그 시점 사진을 갖고 있지 않을 수 있다.** 소재 후보와 사진 보유량을
같이 보고 고른다(실제로 1위 글은 사진 0장, 차순위 글이 ±3일에 49장이었다).

## 2. 사진 매칭

이 맥의 `Photos Library.photoslibrary` 가 아이폰과 실시간 동기화된다(사진 약 1.5만 장).

- `Photos.sqlite` 로 촬영일시·GPS·미디어종류 필터링. 애플이 계산해둔 **미학 점수**도 들어있다
- 로컬 캐시본이 최대 1536×2048이라 iCloud 원본 없이도 릴스 화질이 나온다
- **비전 모델의 분류 라벨만 믿지 말 것.** 캡션 텍스트·사진 속 시각 단서·장수를 삼각 검증한다
- **발행 전 개인정보 검수 필수**: 명찰(실명+직업), 명함(실명+전화+이메일)이 읽히는 클로즈업은
  전부 제외한다. 풀해상도로 확대해서 확인할 것

## 3. 영상 조립 — 하이퍼프레임스

HeyGen의 오픈소스 HyperFrames(HTML→MP4, Apache 2.0). `npx -y hyperframes@latest`

```
lint    조판 검증 (한글 @font-face 누락, GSAP 트윈 충돌 등을 실제로 잡아준다)
render  MP4 렌더 (37초물 기준 약 1분)
beats   음악 비트 감지
```

빌드 스크립트 원본: `~/Projects/ops/offload/jobs/build_v5.py`

**GSAP 함정 2개 (둘 다 실제로 밟았다)**

1. `fromTo` 는 `immediateRender` 기본값 때문에 **타임라인 생성 즉시 from 상태가 적용된다.**
   플래시 오버레이가 영상 전체를 덮는 사고가 났다. 오버레이류는 `immediateRender:false` +
   `tl.set(..., 0)` 으로 초기화할 것
2. CSS에서 부모가 `visibility:hidden` 인데 **자식만 트윈시키면 아무것도 안 보인다.**
   부모 컨테이너에 `tl.set(parent,{autoAlpha:1})` 을 세그먼트 시작 직전에 넣는다

## 4. 세이프존 (필수 검수)

인스타 릴스 UI가 덮는 영역: **상단 220 / 하단 460 / 우측 140px.**
자막은 **화면 55~62% 지점**(`top:1090px` 안팎)에 놓는다. 하단은 캡션·음원이 덮고 터치존이다.

렌더 후 **위험영역을 반투명 빨강으로 덮은 검수 시트**를 만들어 겹침을 눈으로 확인하고 보고한다.
자세한 근거: 볼트 `개념/숏폼 세이프존.md`

## 5. 디자인 — GET100 네오브루탈리즘

겟백 홈페이지 실제 CSS에서 뽑은 값만 쓴다. 감으로 만들지 말 것.

```
블랙 #0d0d0d · 오프화이트 #f5f5f0 · 라임 #d4f000 · 퍼플 #7b2fff
Pretendard (700/800/900) · border-radius 0 · 하드 오프셋 섀도우 (blur 0)
```

구성: 훅 타이포 슬램 → 챕터 넘버 뱃지(라임 사각 + 키워드 카드) → 라임 박스 카라오케 자막
→ 그레인 + 프로그레스바 → 엔드카드(취소선 대비 + GET100 뱃지).
**컷은 1.5~2.2초.** 4초대로 하면 슬라이드쇼로 보인다.

## 6. 사운드

- **BGM**: Mixkit(무료 상업용, 저작자표시 불필요). `https://assets.mixkit.co/music/<id>/<id>.mp3`
  librosa로 BPM·온셋펀치·저음비를 재서 고른다. 말 위에 얹을 거라 펀치는 있되 과하지 않게
- **SFX**: ffmpeg으로 합성한다(라이선스 프리). 위시=핑크노이즈+밴드패스, 히트=저음 사인+감쇠,
  팝=고음 클릭, 라이저=노이즈 스윕
- **믹스**: 나레이션을 키로 **사이드체인 컴프레서**로 BGM을 눌러준다.
  최종 `loudnorm=I=-14:TP=-1` (인스타 기준). 스크립트: `~/Projects/ops/offload/jobs/mix5.sh`

## 7. 발행

`~/Projects/getback/.env` 의 `IG_TOKEN`/`IG_USER_ID` 로 Graph API `media_type=REELS`.
권한·한도(24시간당 100건) 실증 완료.

**단 API 발행은 인스타 인기 음원을 못 붙인다.** 도달에서 음원 비중이 크므로
"완성본을 폰으로 보내 앱에서 음원만 얹는 반자동"이 유효한 대안이다. 어느 쪽인지 밤밤에게 확인.
Meta가 영상을 공개 URL에서 직접 받아가는 구조라 임시 호스팅이 필요하다(맥미니 8765는 테일스케일 내부망이라 불가).
